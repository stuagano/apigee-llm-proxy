# Apigee LLM Proxy

Enterprise-grade API gateway and proxy solution for managing Large Language Model (LLM) interactions with Google Cloud Platform integration.

## Projects

### 1. Cloud Run LLM Proxy
A lightweight proxy service designed to run on Google Cloud Run, providing scalable LLM API management.

### 2. Enterprise AI Gateway
A comprehensive enterprise solution for managing AI/LLM API access with advanced features including:
- Multi-provider support (OpenAI, Anthropic, Google AI, etc.)
- Service account authentication
- Rate limiting and quota management
- Request/response logging
- API key management
- Cloud Run deployment ready
